## Setup for the Simulation

- give subject $j$ in $i$th Treatment group. 
- within the cluster $k$ of total $2K$ cluster. 
- the cluster sample size $m_{k} \sim Normal \Big(\bar m, (\bar m CV_m)^2\Big)$ iid. An inflated Poisson or Negative Binominal?

$$
SD(m_k) = \bar m CV_m
$$

```{r}
set.seed(55555)

K <- 10
m <- 50
CVm <- 0.3
varm <- (m * CVm)^2
size_nb <- m^2 / (varm - m)
mk <- rnbinom(K, mu = m, size = size_nb)
mk
mean(mk)
CV_hat <- sd(mk) / mean(mk)
CV_hat

Xk <- rbinom(K, 1, 0.5) 
Xk
```
